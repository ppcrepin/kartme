Phase 1 — MVP cœur
Compte → créer une course → Elo → résultats → profil.
1.1Authentification
🎨 S0 · S0b · S0c · S0d.
⚙️ Supabase Auth (email + Google + Apple), création de profil, règles de pseudo (3–20, non unique, filtré).
📱🔒🧪 écrans d'auth, session, onboarding pseudo, config OAuth, filtre de mots, tests des 3 voies.
OK si inscription/connexion par les 3 voies · nouveau compte social → S0d · pseudos filtrés/bornés · session persistée.
Dépend de : 0.2, 0.3
1.2Création de course & participants
🎨 C1 · C2 · C3/C3b · C4 · C5 (amis / nom libre / lien-QR).
⚙️ CRUD courses, circuits, profils fantômes, lien/QR, modif lieu/date avant saisie, limite ~10/jour.
📱🔒🧪 flux de création, feuille d'ajout, sélecteurs, liste d'accueil, rate-limit, tests.
OK si course créée avec participants mixtes · lien/QR fonctionnel · modif lieu/date avant résultats · blocage au-delà de 10/jour.
Dépend de : 1.1
1.3Moteur Elopièce maîtresse
⚙️ calcul par paires (K=32, div 400, plancher 100), mapping grades, application atomique, recalcul dans les 24h.
🔒 écriture réservée à l'admin, fenêtre 24h serveur, recalcul non falsifiable côté client.
🧪 tests unitaires : cas de référence (+18/0/−3/−6/−9, paires +6/+5/+4/+3), somme nulle, plancher, cas 2 & 12 joueurs.
OK si résultats identiques aux calculs de référence · somme des Δ nulle · grades corrects.
Dépend de : 0.3
1.4Déroulé de course & résultats
🎨 C6 · C6′ · C6b · C7 · C8 · C9 · C10 · C11.
⚙️ confirmation des présents, soumission classement, signalement non-bloquant, carte de partage (image), état temps réel « en attente ».
📱 grille, présents, glisser-déposer (+ tap séquentiel accessible), attente (drapeau), résultats, détail par paire, partage natif.
🧪 e2e du flux complet créer→présents→saisir→attente→résultats→partage.
OK si flux de bout en bout · bascule attente→résultats en temps réel · carte avec date + tous les finishers · couleur+signe partout.
Dépend de : 1.2, 1.3
1.5Profil, historique & grades
🎨 R1 · R2 · R5.
⚙️📱🧪 agrégats de profil, courbe, historique ; profil (Elo+grade+courbe+stats+badges), échelle des grades colorée, historique cliquable.
OK si profil = bon Elo/grade/stats/courbe/historique · taper une course ouvre ses résultats.
Dépend de : 1.3, 1.4
Fin de Phase 1 = MVP jouable en interne : créer une vraie course, saisir un classement, voir son Elo et son grade évoluer.
